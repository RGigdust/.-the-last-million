// --- كود المباني التفاعلية داخل الكيان --- class EmpireCity extends Phaser.Scene { // ... (تكملة الكود السابق مع التعديل في create) create() { const { width, height } = this.scale; this.physics.world.setBounds(0, 0, width, height); // 1. بناء "منبر الحرية" (مبنى أثري) this.freedomBuilding = this.createStructure(width * 0.2, height * 0.3, '🏛️', 'منبر الحرية', 0x38bdf8); // 2. بناء "البورصة الملكية" (ناطحة سحاب) this.tradingBuilding = this.createStructure(width * 0.8, height * 0.3, '📊', 'البورصة', 0x4ade80); // 3. بناء "المتجر الإمبراطوري" (خزنة ذهب) this.shopBuilding = this.createStructure(width * 0.5, height * 0.7, '🏦', 'المتجر', 0xfbbf24); // الأسد (اللاعب) this.player = this.add.text(width/2, height/2, '🦁', {fontSize: '50px'}).setOrigin(0.5); this.physics.add.existing(this.player); // نظام التصادم: لما الأسد يلمس المبنى يفتح القائمة this.physics.add.overlap(this.player, [this.freedomBuilding, this.tradingBuilding, this.shopBuilding], (p, b) => { this.handleBuildingClick(b.getData('type')); }); this.add.text(width/2, 20, "💡 حرك الأسد نحو المبنى للدخول", {fill: '#aaa'}).setOrigin(0.5); } createStructure(x, y, emoji, name, color) { let container = this.add.container(x, y).setSize(80, 80).setData('type', name); // تأثير توهج تحت المبنى let glow = this.add.circle(0, 0, 40, color, 0.2); let icon = this.add.text(0, -10, emoji, {fontSize: '60px'}).setOrigin(0.5); let label = this.add.text(0, 35, name, {fontSize: '14px', fill: '#fff', backgroundColor: '#000'}).setOrigin(0.5); container.add([glow, icon, label]); this.physics.add.existing(container); return container; } handleBuildingClick(type) { // هنا نفتح النوافذ اللي عملناها قبل كده حسب اسم المبنى console.log("دخول مبنى: " + type); if(type === 'منبر الحرية') this.freedomWin.setVisible(true); if(type === 'البورصة') this.tradingWin.setVisible(true); if(type === 'المتجر') this.shopWin.setVisible(true); } }
